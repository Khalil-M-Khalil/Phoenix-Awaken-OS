FIELD GUIDE

Test the light path

  1. Emitter: select any file type and ignite the stream. The file stays local.
  2. Receiver: open Phoenix Aether on a second device, choose Receive, and start its camera.
  3. Alignment: point the camera at the animated QR. Keep the QR square fully inside the reticle.
  4. Verification: wait for the green SHA-256 match, then save the reconstructed file.
Transfer notes

Files are transferred as binary-safe QR frames with no extension or artificial file-size restriction. Larger files generate more frames and therefore take longer and use more memory. This build verifies integrity with SHA-256 but does not provide encryption or forward-error correction yet.
